## 💧 About the Project

**Master Vodoley** — is a modern, adaptive website created for the **repair, sale, and maintenance of "Vodoliy"("Водолій") pumps** and spare parts.  
The site is designed to represent a real technical service that provides professional repair services and consultations for customers.

The main goal of this project is to provide a clean, functional, and easy-to-navigate platform for showcasing services, products, and contact information in a professional way.

---

## ⚙️ Key Features

- 🏠 **Informative homepage** with navigation and service overview  
- 🧰 **Service (Repair)** page describing repair options and workflow  
- 🛒 **Cart & product functionality** for easy ordering  
- 📱 **Fully responsive design** optimized for desktop and mobile  
- 🎨 **Custom CSS styling** with a consistent color scheme  
- ⚡️ **Vanilla JavaScript interactivity** (dynamic content, buttons, and effects)  
- 📂 **Modular structure** — separate files for each page and function
